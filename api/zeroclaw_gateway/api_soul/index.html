Module api_soul 

Expand description

/api/soul/* — the owner surface of the governed Soul (ADR-015 §7).

Every route is operator-gated: the agent’s Identity and Principles are owner authority, and no model tool, channel identity, or bridge message reaches these handlers. Writes are append-only revisions with an expected-revision check, so a stale editor gets 409 instead of silently overwriting a newer value.

Functions§

get_history
GET /api/soul/history?agent=&layer=identity|principles — every revision of one layer, oldest first.
get_proposals
GET /api/soul/proposals?agent=[&pending=true] — the agent’s own proposals to change its principles or voice, oldest first.
get_soul
GET /api/soul?agent= — current Identity and Principles heads (with revision and source), the configured Voice dials, and whether the legacy persona files are still injected. Seeds missing layers on first read, exactly as the prompt builder does.
post_resolve_proposal
POST /api/soul/proposals/{id}/resolve — the owner’s decision on one of the agent’s proposals (ADR-016 §3). accepted applies the proposal to its layer in the same transaction (optionally reworded with final_text) and returns the applied revision; dismissed applies nothing. Each proposal resolves once. If the change can no longer apply (an invalid field, or a Growth retirement whose entry the owner has since removed or reworded), the proposal stays pending and nothing is applied.
post_rollback
POST /api/soul/rollback — append a new revision equal to an earlier one.
put_growth
PUT /api/soul/growth — owner rewrite of the Growth layer (for example to retire several entries at once or correct the agent’s wording).
put_identity
PUT /api/soul/identity — owner-authored Identity revision. After the first one, the legacy SOUL.md / IDENTITY.md files stop being injected.
put_principles
PUT /api/soul/principles — owner-authored Principles revision.
put_voice
PUT /api/soul/voice — owner write of the stored Voice heads, which layer over the configured persona dials key by key. The owner may set any level.
