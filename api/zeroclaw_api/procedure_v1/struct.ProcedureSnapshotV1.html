Expand description

The immutable procedure snapshot (KP-11 full field set). Constructed only by the runtime mint; carries the COMPLETE captured definition bytes (DECISION KP-16/E option (b): the bytes ride the submit envelope; the retained Tachi-side ref is content-addressed and never resolves through the mutable definitions directory).
