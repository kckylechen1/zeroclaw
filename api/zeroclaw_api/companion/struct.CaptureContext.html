Struct CaptureContext 

pub struct CaptureContext { /* private fields */ }
Expand description

Turn-scoped input to companion capture.

Construct only through the named constructors. Those are the production minting points for CompanionIngress: channel/gateway identities use CompanionIngress::from_channel_identity; trusted CLI uses CompanionIngress::trusted_local_entry. Owner authority is classified here via classify_companion_authority.
