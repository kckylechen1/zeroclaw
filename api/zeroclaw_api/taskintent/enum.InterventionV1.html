Expand description

The frozen 10-op intervention vocabulary (TB-11), ZeroClaw mirror. RequestIndependentReview and Escalate are NOT session interventions — the host refuses them with InterventionError::RequiresNewTaskLineage and the client maps independent review to a NEW task submission (vertical V3).
