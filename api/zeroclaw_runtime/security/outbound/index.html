Module outbound 

Expand description

Outbound response sanitization: tool-protocol stripping, think-tag removal, and credential leak redaction for text that leaves the process for a person (a channel, a gateway client, or a bridge).

Moved here from zeroclaw-channels (orchestrator/outbound_sanitize.rs) so the channels, the gateway /ws/chat stream, and the bridge outbox share one implementation. OutboundStreamRedactor applies the same passes to a streamed reply, holding back any tail that could still turn into a secret.
