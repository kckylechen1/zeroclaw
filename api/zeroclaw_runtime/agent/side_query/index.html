Module side_query 

Expand description

Lock-free read-only side-query (/btw) handle for an super::Agent.

A SideQueryHandle holds an Arc<parking_lot::RwLock<SideQuerySnapshot>> updated by the owning super::Agent at construction, configuration/history mutations, turn start, and each completed tool round. Callers (such as the WebSocket gateway) can clone the handle and answer a one-shot /btw question concurrently while a main turn holds the Agent’s &mut self lock, without mutating conversation history, session storage, steering queues, or turn state.
