Function settle_announcement_guards 

pub fn settle_announcement_guards<T: TurnOutcome>(
    guards: impl IntoIterator<Item = UnclaimOnDrop>,
    outcome: T,
) -> T
Expand description

Settle every guard a turn claimed against that turn’s one outcome, and give the outcome back.

A streamed turn can claim more than once — the opening user message plus each mid-turn steering message — and those guards stand or fall together: one provider call either read all of them or none, and keeping one while returning another would either repeat a completion or lose it. Taking anything that yields guards means the single-claim sites (Option<UnclaimOnDrop>) and the many-claim site (Vec<UnclaimOnDrop>) settle through this one function instead of through two.
