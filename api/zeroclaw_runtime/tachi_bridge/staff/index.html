Module staff 

Expand description

Compatibility exports while the retired TaskIntent port remains. The Staff transport belongs to the tool crate; shared receipts to the API crate.

Client of Tachi’s tachi_staff MCP tool over ZeroClaw’s MCP HTTP transport. One MCP session is opened lazily and reused for this client’s lifetime. A transport failure drops it so the next call opens a fresh one.
