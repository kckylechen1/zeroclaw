Module mcp_era 

Expand description

Dual-era MCP peer classification and modern-wire helpers.

Protocol version 2026-07-28 removed the initialize handshake. Probe once per server, resolve a PeerEra, and branch handshake / session / transport on that one value. Modern peers speak POST headers and per-request _meta; Legacy peers keep initialize. The client’s declared revision MCP_PROTOCOL_VERSION equals MCP_MODERN_PROTOCOL_VERSION.
