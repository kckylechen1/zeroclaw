In-process backend that carries commands to the coordinator actor.

Cloning is cheap and every clone talks to the same actor.

pub async fn spawn( &self, request: ChildRequest, ) -> Result<ChildResult, CoordinatorError>

Spawn a child and await its result.

A blocking caller awaits this directly; a background caller spawns a task around it and drops the receiver, which the coordinator reads as “nobody is waiting inline”.

Admission is awaited first and separately. That await is bounded by the actor’s own decision, not by the child: the coordinator answers it inside the same command arm that decides. A refusal therefore returns here immediately, as CoordinatorError::Refused carrying the structured reason — never as a ChildResult, because no child ran.

§Errors

CoordinatorError when the child was refused, the actor is unreachable, or a reply was lost. A child that ran and merely failed returns Ok with a failed outcome.
