Function exceeds_spawn_depth 

pub fn exceeds_spawn_depth(depth: u32, max: u32) -> bool
Expand description

Pure predicate for the spawn-depth gate — separated from the actor’s live registry read so it is unit-testable, the way delegation’s own backstop predicate is.

depth is the depth of the child being admitted, not its parent’s: ChildOverrides::spawn_depth is what the sole existing reader of that field files as the child’s own TaskRecord.depth (zeroclaw-runtime/src/control_plane/subagent_persistence.rs). A child at exactly max is therefore admitted and only its would-be child is not — which is the same frontier delegation draws when it refuses a caller whose own depth has already reached max_delegation_depth.
