Module task_list 

Expand description

Model-facing durable task-list tool (#567/#568): cross-session commitments with server-minted stable ids and revision-checked batched writes, each optionally carrying a reminder occurrence. This is NOT the current-step plan (that is TodoWrite) — items here are multi-day commitments that survive restarts and session changes.
