Module soul_check 

Expand description

Behavioral continuity check for the Soul (ADR-018 §5).

A fixed, repository-owned set of scenarios is sent to each selected model with the agent’s real Soul projection as the system prompt and no tools. One judge model then scores every reply against a repository-owned rubric: dial scenarios get a level on the same five-step scale as the Tone dials, floor scenarios get pass/fail. The report flags dials judged two or more levels from their setting, dials two or more levels apart between targets, and failed floors.

This is an owner-run diagnostic. It spends real model calls, an LLM judge is a signal rather than proof, and nothing here is stored.
