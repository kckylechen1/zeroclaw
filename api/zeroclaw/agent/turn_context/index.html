Module turn_context 

Expand description

Per-turn owner context for the body agent (#380 U3).

Two governed projections reach the system prompt of every body turn, in a fixed order and each within its own byte bound:

  1. the Soul (persona_projection), rendered in the prompt builder’s persona slot. It is re-projected only when the store’s revision stamp moved since the last turn, so an owner-approved change applies from the next turn of a live session while an unchanged Soul keeps the prompt bytes (and the provider’s prompt cache) stable;
  2. the User Model owner profile (user_model_section), appended at the end of the system prompt, bounded by USER_MODEL_PROJECTION_DEFAULT_MAX_CHARS.

Only body agents opt in (see AgentBuilder::turn_context). Delegated workers build their own bounded prompt and never receive either section.
