Condition comparison-operator catalog. Definition-format surface only: the legacy run-side evaluator was deleted with the SOP run side, and what survives is the operator set authoring surfaces render when building the condition strings stored on triggers and steps.

ConditionOp
A condition comparison operator. This enum is the single source of truth for the operator set: every authoring surface renders the list this enum yields (via ConditionOp::catalog). Adding an operator here is the only edit needed; no surface hand-lists operators.
