Module agent_tasks 

Expand description

Durable agent task list (#567): cross-session commitments owned by the companion agent identity (a mint-once UUID string, resolved by the caller — the store is identity-agnostic). Item identity is a server-minted UUID, never reused; every mutation batch is transactional and checked against the owner’s monotonic list revision.
