zeroclaw::channels

Enumerate the channel types compiled into this binary.

Functions§

compiled_channels
Channels available in this binary: compiled feature specs minus retired transports. Retired kinds (empty channel-* feature stubs since the runner retirement, #579/#581) must never be listed as connectable — the feature flag alone no longer proves a runner exists.
configured_retired_channels
Retired transports with a populated [channels.<kind>] section. The section still parses (schema retirement is evidence-gated in #584), but nothing consumes it — surfaces report these distinctly instead of presenting them as configured channels.
configured_uncompiled_channels
Live channel kinds that are configured but whose feature is not enabled in this build. Retired transports are excluded — they belong to configured_retired_channels, not to a rebuild hint (rebuilding with their stub feature would not bring a runner back).
is_channel_type_compiled
Returns whether a schema channel type key is compiled into this binary. Accepts both kebab-case keys emitted by the config schema and legacy underscore spellings used in channel references.
